# 2026-05-15

## HMLV生产看板修复

1. **WIP接口硬编码月份问题**：`/api/wip` 接口原来硬编码 `may_start/may_end = datetime(2026,5,1~31)`，导致始终只显示5月数据。已改为动态计算当前月的起止日期（`month_start/month_end`），使用 `calendar.monthrange()` 自动获取当月天数，确保跨月后数据自动切换。

2. **"累计完成工单"改为当月统计**：
   - 后端：移除 `/api/data` 接口 `station_stats` 中的 `done_all` 字段（所有月份累计），只保留 `done`（当月完成数）
   - 前端：`renderStationTable` 中"累计完成工单"列和"工单进度"百分比现在使用当月数据（`done`）而非全量数据（`done_all`）
